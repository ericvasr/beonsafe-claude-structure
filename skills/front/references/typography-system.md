# Typography System — Pairings + Rules

> Pareamentos tipográficos derivados de [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) (MIT, Copyright (c) 2024 Next Level Builder). Reescrito. Ver `../PROCEDENCIA.md`.

## Universal bans

| Banned for display | Reason |
|--------------------|--------|
| `Inter` | The trained-data default. Sniffable from miles. |
| `Roboto` | Same — Google default, invisible voice. |
| `Arial`, `Helvetica` (web-served) | System default, no character. (System-stack as a deliberate iA-style choice is OK.) |
| `Open Sans`, `Lato`, `Nunito` | Generic SaaS defaults. |
| Anything that ships in <2 weights | Can't build hierarchy with one weight. |

| Banned for body | Reason |
|-----------------|--------|
| `Times New Roman` web-served | Browser default — reads as "no design". |
| Decorative scripts as body | Illegible at small size. |
| Monospace as body (except for code/data) | Type rhythm fights reading flow. |

## Pairing rules

1. **Pair faces with different character, not different families of the same style.**
   - GOOD: Newsreader (serif display) + Geist (geometric sans body)
   - BAD: Inter (geometric sans) + Roboto (geometric sans) — same character, no contrast

2. **Weight contrast ≥ 300 between hierarchy levels.**
   - H1: 700, body: 400 = good
   - H1: 600, body: 500 = too close

3. **Max 2 typeface families per project.** (Plus 1 mono = 3 max total.)

4. **Match icon weight to body weight.** If body is 400, use 1.4–1.6 stroke icons. If body is 500–600, use 1.6–2px.

5. **Line-height + line-length:**
   - Body sans: line-height 1.45–1.6, line-length 45–75ch
   - Body serif: line-height 1.5–1.7, line-length 50–75ch
   - Headings: line-height 1.1–1.3

6. **Tracking (letter-spacing):**
   - Large display (60px+): -1 to -2% (tighten)
   - Body: 0 (default)
   - UPPERCASE LABELS: +5 to +15% (open up; small uppercase compresses badly)
   - Mono labels uppercase: +15 to +20% (mono is already wide, push further for label feel)

## Type scale (modular)

Pick one ratio and stick to it:

| Ratio | Mood | Scale (base 16px) |
|-------|------|--------------------|
| 1.125 | Subtle, dense | 16 / 18 / 20 / 23 / 26 / 29 |
| 1.2 | Calm | 16 / 19 / 23 / 28 / 33 / 40 |
| 1.25 (Major Third) | Most common | 16 / 20 / 25 / 31 / 39 / 49 |
| 1.333 (Perfect Fourth) | Dramatic | 16 / 21 / 28 / 38 / 50 / 67 |
| 1.5 (Perfect Fifth) | Editorial | 16 / 24 / 36 / 54 / 81 / 121 |
| 1.618 (Golden) | Editorial-extreme | 16 / 26 / 42 / 68 / 110 |

For most product UIs, use 1.25 or 1.333. For editorial / luxury, use 1.5 or 1.618.

In Tailwind / framework code, prefer `clamp()` for fluid type:
```css
font-size: clamp(2.5rem, 4vw + 1rem, 5rem);
```

## Self-audit (run on every deliverable)

- [ ] Display face is NOT Inter / Roboto / Arial / Open Sans
- [ ] At most 2 faces (3 with mono)
- [ ] Weight contrast ≥ 300 between hero and body
- [ ] Body line-length 45–75ch
- [ ] Body line-height 1.45+
- [ ] Headings line-height 1.1–1.3
- [ ] No mid-paragraph em dashes (use commas / parens / colons)
- [ ] Icon stroke matches body weight
- [ ] UPPERCASE labels have +5–15% tracking
- [ ] Single type scale ratio used throughout
- [ ] Custom shadcn defaults (radii, color tokens) — NOT untouched defaults
